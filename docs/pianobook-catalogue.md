# Pianobook catalogue — 10 packs per category

Generated by `scripts/pianobook.sh list all 10` on 2026-10-24.

**Read this first.** The list is in the site's public order, not its review order: the
"Highest rated" sort is computed in the browser from review data that pianobook.co.uk
does not expose to requests (its filter endpoint answers `{"success":false}` without a
session nonce). Downloading also needs a free account — the pack pages answer
"Log in to download" without a session cookie, and the browser's cookie store cannot be
reused here (Chrome/Edge encrypt them with a key held by the GNOME keyring, and
`secret-tool` is not installed). So: browse the links below, download what you want while
logged in, then run `scripts/pianobook.sh import ~/Downloads`.

Formats decide the player: `.dspreset` → Decent Sampler, `.nki` → Kontakt (already
installed here), `.sfz` → an SFZ player. See `scripts/pianobook.sh players`.
